# Стартап в информационных технологиях — Команда №6
Репозиторий по учебной дисциплине **«Стартап в информационных технологиях»**.

## Проект: litekiz

litekiz — единая панель контроля маркированного товара: коды «Честного ЗНАКа», остатки и движение товара по всем площадкам.

- `reports/` — учебные отчёты по семестрам и неделям
- `project/` — код: `backend/` (FastAPI) и `frontend/` (React)
